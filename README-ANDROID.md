# SHADOW COPY 3D — Android Packaging Guide

This folder is a complete, ready-to-build Android project for **SHADOW COPY 3D**,
built with [Capacitor](https://capacitorjs.com) (free, open source, no backend,
no account, no subscription). The game itself is 100% offline — it loads no
files from the internet, needs no account, and requests **no Android
permissions**.

## What's in here

| Path | What it is |
|---|---|
| `www/index.html` | The 3D game (single self-contained file, ~694 KB, Three.js inlined) |
| `capacitor.config.json` | App id `com.shadowcopy.game`, name "Shadow Copy" |
| `android/` | Real native Android project (generated by Capacitor) |
| `package.json` | Node dependencies for the Capacitor CLI |
| `play-store-icon-512.png` | 512×512 store icon — upload this in the Play Console |
| `PRIVACY_POLICY.md` | Privacy policy draft — host it publicly, paste the URL in the console |
| `PLAY-STORE-GUIDE.md` | Step-by-step Play Store publishing walkthrough |
| `STORE-LISTING.md` | Ready-to-paste store listing text + data safety answers |

## Prerequisites (one-time, on your computer)

1. **Node.js 18+** — https://nodejs.org
2. **Android Studio** (latest) — https://developer.android.com/studio
   - During setup, install the Android SDK + a device emulator (API 36).
3. **Java 17** — Android Studio bundles this; you don't need to install it separately.

## Build a debug APK for testing on your phone (fastest path)

1. **Unzip** `shadow-copy-3d-android.zip` on your computer.
2. Install the prerequisites above (one time).
3. Open a terminal in the unzipped folder and run:
   ```bash
   npm install
   npx cap sync android
   ```
   (This copies the game into the native project. Re-run `npx cap sync android`
   every time you replace `www/index.html` with a newer version.)
4. Open the project in Android Studio: **File → Open…** and select the
   `android` folder inside the unzipped project. Wait for Gradle sync to finish
   (first run downloads dependencies — needs internet).
5. **Enable Developer Options + USB debugging** on your phone:
   Settings → About phone → tap "Build number" 7 times → back to Settings →
   Developer options → enable "USB debugging".
6. **Connect the phone** via USB, accept the "Allow USB debugging?" prompt.
7. In Android Studio, pick your phone in the device dropdown (top toolbar),
   then click **Run ▶** (or Shift+F10). Android Studio builds a debug APK,
   installs it, and launches the game on your phone.
8. To get the APK **file** itself (to share/install manually):
   **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. When it finishes,
   click "locate" in the notification — the file is
   `android/app/build/outputs/apk/debug/app-debug.apk`.
   Copy it to your phone and tap it to install (allow "Install unknown apps"
   for your file manager/browser when asked).

## Build the signed release AAB for the Play Store

Play requires an **App Bundle (.aab)**, not an APK, for new apps.

1. `npm install` and `npx cap sync android` (as above), then open the
   `android` folder in Android Studio.
2. **Build → Generate Signed App Bundle / APK…**
3. Choose **Android App Bundle**, click Next.
4. **Key store path → Create new…** (first time only). This creates your
   **upload key** (a `.jks` file + passwords).
   - **BACK THIS FILE UP IN TWO PLACES (USB drive + cloud). Losing it means
     you can never update your app on Play again.**
   - Remember the key store password, key alias, and key password.
5. Choose the **release** build variant, finish the wizard.
6. The signed `.aab` appears under `android/app/release/` (file name like
   `app-release.aab`). Upload that file to the Play Console — see
   `PLAY-STORE-GUIDE.md`.

Alternative (command line, if you already have a keystore):

```bash
keytool -genkeypair -v -keystore upload-keystore.jks -alias shadowcopy \
  -keyalg RSA -keysize 2048 -validity 10000
```

then create `android/keystore.properties` (never commit it anywhere) and wire
it into the release signing config, or simply use the Android Studio wizard
above — it does the same thing.

## Updating the game later

1. Replace `www/index.html` with the new game file.
2. Run `npx cap sync android`.
3. Bump `versionCode` (must increase every release) and `versionName` in
   `android/app/build.gradle`.
4. Rebuild the signed AAB and upload it to the same Play Console app.

## Before first publish — manual steps checklist

- [ ] **Play Console account** — one-time $25 registration at play.google.com/console.
- [ ] **Package name** — `com.shadowcopy.game`. You cannot change it after the
      first upload. To use your own id instead, change `appId` in
      `capacitor.config.json`, delete `android/`, and re-run `npx cap add android`.
- [ ] **App icon** — the included 512×512 PNG is ready to upload; Android
      Studio can also generate adaptive icons (right-click
      `android/app/src/main/res` → New → Image Asset).
- [ ] **Feature graphic** — 1024×500 banner for the store listing (make in any
      image editor; not included).
- [ ] **Screenshots** — at least 2 phone screenshots (capture them from the
      game running on your phone or an emulator).
- [ ] **Privacy policy** — required by Play even though the game collects
      nothing. Host `PRIVACY_POLICY.md` publicly (GitHub Pages, your site)
      and paste the URL in the console.
- [ ] **Content rating questionnaire** — fill it in the Play Console
      (expect "Everyone" for this game: no violence against humans, no
      gambling, no chat).
- [ ] **Data safety form** — declare "no data collected" (answers are ready in
      `STORE-LISTING.md`).
- [ ] **Test on a real device first** — install the debug APK: check touch
      controls, sound, vibration, pause menu, and that progress saves after
      closing and reopening the app.

## Notes

- `minSdkVersion = 24` → runs on Android 7.0 and newer (covers ~all active devices).
- `targetSdkVersion = 36` → meets Play's current requirement for new apps.
- All saves use the device's local storage — no account, no cloud, no internet.
- The game runs inside the app's WebView; it is a real, fully playable 3D
  game, not a website wrapper around a demo.
- Why no APK is included here: APK/AAB builds require Android Studio on your
  computer (Gradle cannot run in the assistant's environment). This project
  is complete and verified buildable — manifest, sources, resources,
  targetSdk 36, applicationId, and release build type are all in place.
